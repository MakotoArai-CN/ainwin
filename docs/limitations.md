# 已知限制

## 结果悬停

Win顺 0.15 的原生悬停是 NameTip，只在名称或文件夹被截断时出现，显示完整名称、文件夹、路径、大小、时间。插件行在宿主里是 `AppKind::Plugin`，内部路径是 `winshun-plugin:...`，不能复用原生文件行的悬停。

插件已做：

- 结果第二行显示所在文件夹；
- `modified` / `size` / `open.path` 使用原生字段；
- 右键「详细信息」显示完整路径、时间、大小和命中原因；
- `preview.text` 继续发送，等宿主支持时可直接使用。

## 搜索范围

- 只搜 Win顺 已索引的位置；未索引磁盘、网络盘、压缩包内部、图片 OCR 不在范围。
- 聊天软件只扫传输/接收目录；客户端配置、缓存、表情、缩略图不扫。
- 微信/QQ 的加密 `.dat` 图片/视频跳过，避免给出打不开的文件。
- `没有打开过` 不能作为条件：索引没有可靠访问时间。
- `.ts` 归代码类型；真正的 MPEG-TS 视频请用 `ext:ts`。
- 一次请求最多 200 条；`0` 表示不限时的上限也是 200。

## 模型

- `large` 不随包，测试机上端到端超过 Win顺 10 秒超时。
- 多语言模型未随包；当前 tokenizer 只支持 WordPiece。
- 更大模型不一定更准，且明确更慢；数字见 [bench/README.md](bench/README.md)。

## 宿主

- 插件行是应用行，原生磁盘文件预览/悬停不能直接套用。
- 关键字默认值可能和 Win顺 自带搜索或其他插件冲突；用户设置的关键字优先，可在「设置 → 插件」修改。
