# 设置、文件夹与聊天文件

## 常用文件夹

`桌面`、`下载`、`文档`、`图片`、`音乐`、`视频`、`OneDrive`、`D盘` 以及对应英文（`desktop`、`download`、`documents`、`pictures`、`music`、`videos`）。

句首的“文档”不再当文档类型：`文档`、`document` 默认指 Documents 文件夹；“合同的文档”“合同文档”才是文档类型。目的和类型冲突时，带“里面的”“文件夹”“folder”的语境优先当目录。

## 复杂查询

- 多个类型取并集：`word和excel`、`视频和安装包`
- 多个文件夹取并集：`桌面和文档`
- 双边界：`大于1M小于50M`
- 时间：`昨天`、`上周`、`上季度`、`下午3点以后`
- 排除：`除了安装包以外`、`不要ts`
- 连接词不会变成文件名条件：`收到`、`发来`、`修改过`、`按时间倒序`

`没有打开过` 目前不能作为条件：Windows 搜索索引没有可靠的访问时间，插件会忽略这个词。

## 聊天/办公软件

| 来源 | 目录 |
|---|---|
| 微信 | `WeChat Files` / `xwechat_files` 的 `FileStorage`、`MsgAttach`、`msg` |
| QQ | `Tencent Files` 的 `FileRecv`、`nt_data\File/Pic/Video` |
| 企业微信 | `WXWork` 的文件/图片/视频、`Cache\File` |
| 钉钉 | `DingTalk` 的文件/图片/视频 |
| 飞书 | `Feishu` / `Lark` |
| WPS | `WPS Cloud Files` |

客户端配置、缓存、表情、缩略图和加密 `.dat` 不进入结果。目录可在「聊天/办公软件文件目录」里改。

命中后排在文件结果上方，Enter 打开设置页、`.cpl`/`.msc` 或系统属性。
